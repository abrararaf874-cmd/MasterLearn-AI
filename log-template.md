# Weekly Log Template

Copy this block each week and fill it in as you go.

```
## Week of [DATE]

Topic: [status] | Topic: [status] | Topic: [status]

Legend: mastered | shaky (reason) | not started
```

### Example

```
## Week of 2026-08-24

Matrices: mastered | Vectors: shaky (row reduction) | Circle: not started
```
